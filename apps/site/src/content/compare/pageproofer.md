## Where PageProofer charges and MarkLayer doesn't

PageProofer has no free plan, and its FAQ says why: the company needs revenue to keep supporting the product. Freelancer is $39 a month for five users. The sixth user is $5 a month, or the jump to Team at $89 buys 25. Agency at $199 removes the user cap and adds custom branding. Sites are unlimited on every plan, which is unusual: [SureFeedback](/vs/surefeedback) counts them. The trial is 15 days with no card.

MarkLayer has no seat count or plan. A share link is the whole unit and you can mint as many as you want. What you give up is the dashboard: tags, due dates, an overdue filter, and an activity tab that shows what an agent changed. MarkLayer has a kanban board with status columns per link and nothing more.

## The embed in the footer

PageProofer runs on a script in the site's footer, or a plugin on WordPress and Craft CMS. The Chrome and Edge extension is a convenience for your own team and does not replace the embed. The help page is direct about it: clients, guests and website visitors still need the embed code to see PageProofer. So someone with deploy access adds the script before a client can comment.

MarkLayer fetches the page from its own server and overlays the canvas, so a public URL needs nothing at all. A page behind a password or a login needs the free browser extension, which annotates in the tab where you are already signed in. Neither route touches the site's code. The embed does buy PageProofer something real: because its script runs inside the page, every note arrives with the browser, OS, screen size, recent console errors and failed network requests. MarkLayer captures only the element's selector and markdown and your screenshot. For a developer chasing a bug, PageProofer's note is the better bug report.

## The agent on the other end

Both tools talk to Claude Code, Cursor and other MCP clients, and both include it without an extra fee. PageProofer hands the agent a full note, console errors included, lets it reply, and routes a fixed note to Review so a person signs off. That human gate is a sensible default.

MarkLayer's is free and needs no plan or key. Every share link is itself an MCP server, so `claude mcp add --transport http marklayer https://marklayer.app/s/<id>/mcp` is the whole setup. The agent watches the room live, acknowledges a thread so the reviewer sees it is in progress, resolves or dismisses it with a reason, and replies. It can leave its own comment pins and propose exact text replacements the reviewer accepts as a diff. It can never mark a thread approved.
